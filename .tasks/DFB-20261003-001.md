## Context

`deepfreeze.ps1` 是仿 Windows 冰点还原的**目录级**快照/还原工具（PowerShell 5.1 单文件，
4 子命令：protect / restore / status / unprotect），安全边界：`$AllowedRoot='D:\15812'`、
junction/symlink 按真实目标判定并拒绝越界、`/XD` 排除 `.freeze` 与 `.freeze-snap`。

P0 目标（PLAN-P0 §4）：把「只能还原到 protect 瞬间」升级为**多时间点快照**——
restore 可回滚到任意历史快照，默认还原最新；快照按 `KeepSnapshots`（默认 2）轮转；
清单（manifest）从快照目录内迁到 `.freeze\manifests\`，根治 restore 时
robocopy /MIR 把 manifest 拷回源根的自我污染 bug（PLAN-P0 已知缺陷）。

**明确不做**（PLAN-P0 §6/6.5，评审不得以此为由打回）：注册表/系统服务/环境变量/
已装软件（需内核驱动，成本不成比例）、外部副作用、进程内存态、开机自动还原。
