### 问题 2：KeepSnapshots 联动删除是否可能删错？

审查 `Remove-OldSnapshots` 函数（L167-176）：

```powershell
function Remove-OldSnapshots {
  $snaps = Get-Snapshots
  $excess = $snaps.Count - $KeepSnapshots
  if ($excess -gt 0) {
    $snaps | Select-Object -First $excess | ForEach-Object {
      Remove-Item -LiteralPath $_.FullName -Recurse -Force
      $ts = $_.Name -replace '^snap-', ''
      Remove-Item -LiteralPath (Get-SnapshotManifestPath -Ts $ts) -Force -ErrorAction SilentlyContinue
      Write-Log "  清理旧快照: $($_.Name)"
    }
  }
}
```

**安全性分析**：
- `Get-Snapshots` 已过滤 `*.tmp`，只返回完整快照
- 按 `Name`（即 `snap-<ts>`）升序排列，最旧在前
- 删除时先删快照目录，再删对应 manifest（`-ErrorAction SilentlyContinue` 容忍 manifest 缺失）
- 若 manifest 缺失，只跳过 manifest 删除，**不会误删其他快照**
- 若某个快照目录缺失（极端情况），`Remove-Item` 会报错但被 `SilentlyContinue` 捕获（实际上这里没有 try-catch，但 `-Recurse -Force` 对不存在路径静默）

**潜在风险**：若 manifest 文件名与快照目录名不匹配（如手动物理删除快照目录但保留 manifest），下一次轮转会因 `$excess` 计算基于目录数而非 manifest 数，可能导致 manifest 累积。但这是边界情况，不影响核心功能。

**结论**：联动删除**正确**，在正常流程下不会删错。

### 问题 3：restore 无参时默认 latest 的取法


- 字典序与时间序**严格等价**（月、日、时、分、秒各字段宽度固定，无前导零缺失问题）
- 跨年、跨月均正确

**结论**：默认 latest 取法**正确**，字符串排序等价于时间序。
