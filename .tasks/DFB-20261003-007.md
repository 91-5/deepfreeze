## Context

agent-covenant `tools/gate.py` 要求 verdict schema：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | str | 必须 == 文件名（不含 `.verdict.json`） |
| `verdict` | str ∈ {PASS, CONDITIONAL, FAIL} | 字面枚举 |
| `blockers` | int | PASS 必须 = 0；CONDITIONAL 可 > 0 |
| `independent` | bool | true（除非带 `--allow-nonindependent`） |
| `verifier` | str | 评审人 |
| `ts` | ISO 8601 | 时间戳 |
| `evidence` | list[str] | 顶层非空字符串列表 |

deepfreeze 现存两张 verdict 用了**自定义 schema**：

| 项 | 001 verdict | 002 verdict |
|---|---|---|
| `id` 字段名 | `task_id` | `card_id` |
| `verdict` 值 | `APPROVED` | `APPROVED_WITH_NOTES` |
| `blockers` | 缺失 | `[]`（空数组） |
| `independent` | 缺失 | `true` |
| `verifier` 字段名 | `reviewer` | `reviewer` |
| `ts` 字段名/格式 | `review_date`（仅日期） | `reviewed_at`（ISO） |
| 顶层 `evidence` | 缺失（嵌套在 conclusions） | 缺失（嵌套在 acceptance_criteria） |

导致 **两张 verdict 自 round 1 闭合起就从未通过 `gate.py`**。

## B. lint_cards.py 补丁

### B1. 新增检查函数 `check_verdict_schema(verdict_dir)`

对 `verdict_dir` 下每个 verdict 文件，复用 `gate.py` 的：
- `load_verdict(verdict_dir, vid)` —— 解析
- `_check_fields` —— 必填字段
- `_check_verdict_value` —— verdict ∈ 枚举
- `_check_blockers` —— blockers 整数
- `_check_independence` —— independent == true
- `_check_evidence` —— 顶层 evidence 非空 list[str]
- `parse_ts` —— ts 可解析

任一不合规 → **ERROR** 级 finding。

### B2. 接入主流程

在 `lint_cards.py` 主入口 `run_lint()`（或类似聚合点）调用 `check_verdict_schema(verdict_dir)`，
把 findings 合入返回。

### B3. 边界

- 与 `check_verdict_pairs` 解耦：schema 检查独立于「卡-评审-裁决」配对。
- 不动 `lint_cards.py` 现有任何规则；纯新增。
